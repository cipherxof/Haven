# MGO2 from-scratch collision writer (Python reference implementation)

Generates a complete `.geom` section 0 (the collision database) for an MGO2
stage from a glTF exported by Haven or authored in Blender, splices it into a
stock geom, and verifies it offline. Proven in game on 2026-09-12: Ambush
Alley's (n002a) entire collision regenerated by this writer, walkable
everywhere, plus a Blood Bath concrete block transplanted into it with its
visual and its collision.

This is Python, not C#, and it is a reference implementation: every engine
rule below was found by loading the file in the game and watching what
happened, so the value is in the rules and the gates as much as the code.

## Pipeline

    glTF (Haven export / Blender, materials named attr_0x<64-bit attribute>)
      -> gltf_faces.load()                      triangles + per-primitive attribute + nameHash
      -> FieldChainedWorld(faces, single_owner='ground')      cellfirst_fields.py
      -> world.emit(base_off, world_trailer)                   section 0 bytes
      -> splice_payload(donor_plain, entries, payload, pad_to=len(donor))
      -> GATES
      -> mgo2_stage_crypto.encrypt(plain, 'stage/<name>') + carried trailer

`collision_canary_build.py` is the end-to-end driver used for every in-game
round (it also authors a test object and relocates the PRP_CBOX item spawns;
strip that for real use). `transplant_wedge.py` / `transplant_block.py` move a
prop (visual + collision) from one stage to another.

## Engine rules (each one cost an in-game round)

1. **Cell-first blocks.** One chain of blocks per occupied grid cell; block
   origin (vertex-pool row 0) = the cell's min corner. Descriptor table in
   (x,y,z) lexicographic cell order, ending exactly at the first block.
2. **Nodes are walked by LINKS, not by size.** A block with N POLY leaves
   needs a FIELD chain: FIELD k (0x40 B: len 1, type 0x04, cls 0x2004,
   next -> FIELD k+1, prev -> FIELD k-1, child +4 -> its POLY, name 0,
   attr = the POLY's attr; body = half-extent+100 (3f), i16 0, u16 0, AABB
   centre (3f), u32 0) followed by its POLY. Links are signed offsets in
   0x10-byte units relative to the node. FIELD-less blocks are valid only
   with a single leaf. Symptom when wrong: spawn on ground, fall on the
   first step (only leaf 0 of every block exists).
3. **desc.b1 = node count (FIELDs + POLYs), desc.f4 = offset/16 of the last
   root** reached by following Next from node 0. POLY +0x14 = (pool-node)/16.
4. **Floor faces (|ny| > 0.5) must be stored in EVERY cell their AABB
   overlaps, including every Y cell.** The ground probe asks the cell the
   player's origin is in (~800 above the feet); a floor just under a Y
   boundary stored only in the lower cell is shootable but not standable.
   Walls single-owner (centroid cell) for size; a wall that straddles a cell
   edge is not seen from the other cell (known gap).
5. **The attribute word (leaf +0x18, u64) decides who collides.** Stock keeps
   two copies of a surface: a character copy (floor 0x20a000834, blocking
   wall 0x208202830) and a projectile/camera copy (0x100840dc2). A surface
   with only the scenery word stops bullets, the camera and dropped items;
   the player walks through it.
6. **Character collision is one-sided.** Wind faces so (b-a)x(c-a) is the
   outward normal (floors +Y). Inward walls admit and then trap.
7. **dl/p geoms must keep their exact plaintext size**; pad to the donor.
   Carry the donor's encrypted trailer verbatim (16 B here, not always).
8. **Transplant a prop's collision verbatim.** Attributes, leaf names,
   per-face material words and winding, straight from the source stage.
   Authored replacement shells for the same object (a closed prism, a
   stepped ramp) hung the game on approach every time while the verbatim
   copy did not; the cause of those hangs was not isolated. Konami's shells
   are only closed in context: check boundary edges and add a sealing wall
   where the object leaned on something.
9. Caps: 32 faces per leaf (stock max 33), 1024 verts / 256 normals per
   block (10-bit indices, 1-byte plane index), 32 leaves per block, block
   arena 0x3B70 B, chain length <= 10 preferred.
10. Visual transplant: props sub-meshes use 28/32/36/40-byte vertex layouts
    (0x10 pos, 0xa2 normal, 0x83 colour, 0x78.. UV sets, 0xae tangent,
    0x81/0x97 skinning). Convert per attribute. Vertex colour alpha of 0x00 or
    0x80 renders invisible; force 0xff. A prop as drawn is usually SEVERAL
    connected components (top skin, side slabs, end faces) in one sub-mesh.

## Gates (all must pass before a load is worth spending)

    geom_io round-trip byte-identical; every block's node walk exact
    refs / routes pointer counts unchanged after the splice
    link_reach_file(g) == leaf count            (cellfirst_fields.py)  <- rule 2
    bp_reach.score() >= 96% (stock 97-100%)      (bp_reach.py)          <- rule 1
    stand-in-cell oracle == stock                (see collision_canary_build history) <- rule 4
    plaintext size == donor; encrypt->decrypt round-trip

## Files

    cellfirst_fields.py       FieldChainedWorld (rules 2-4) + link_reach_file gate
    cellfirst_build.py        AttrChainedWorld, splice_payload, pointer checks, CLI
    collision_canary_build.py end-to-end driver used for the in-game proofs
    transplant_wedge.py       one prop component, visual + collision, stage to stage
    transplant_block.py       a co-located assembly of components (the real block)
    gltf_faces.py             glTF -> Face objects (Haven conventions)
    geom_build.py             base cell-first writer, Face, constants
    geom_build_chain.py       chained blocks per cell, count_nodes, last_root_offset16
    geom_io.py                structured .geom parser/writer (round-trips 919/919 shipped geoms)
    bp_reach.py               broadphase reachability gate
    dar_io.py / mdn_io.py     .dar archive and .mdn mesh access (visual side)
    mgo2_stage_crypto.py      stage crypto (pip install pycryptodome)

All modules are siblings; run from this directory. The transplant and
canary scripts still carry the author's local data paths as constants at
the top; edit those for your install.

## In-game evidence timeline (Ambush Alley, 2026-09-12)

    v1  FIELD-less, single-owner          -> fell through on first step        (rule 2)
    v2  FIELD chain                       -> floor holds, random holes          (rule 4)
    v4  ground mode, all Y cells          -> walked everywhere, no fall-through
    v6  block + PRP_CBOX relocated        -> boxes rest on the block, camera hits it, player walks through (rule 5)
    v7  character + scenery attrs         -> walked in, could not get out        (rule 6)
    v8  outward winding                   -> "it worked im up on an invisible box"
    -   authored prism / stepped ramp     -> hang on approach (not isolated; see rule 8)
    -   Blood Bath wedge collision verbatim -> no hang, walkable
    -   full concrete block, visual+collision -> standing on it (video)
